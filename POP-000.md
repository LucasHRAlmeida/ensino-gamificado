# POP 000 — Procedimento Operacional Padrão para Agentes

> **Status:** v1 (base inicial — sujeita a revisão pelo responsável)
> **Responsável:** Dr Lucas HR (@LucasHRAlmeida)
> **Aplica-se a:** todo agente de IA (Claude, Grok, GitHub Copilot, etc.) **e** colaborador humano que for alterar este repositório.

## 1. Objetivo

Padronizar como agentes automatizados e colaboradores operam neste repositório, evitando **quebras silenciosas** — em especial na publicação via GitHub Pages — e garantindo rastreabilidade das alterações.

## 2. Leitura obrigatória (antes de qualquer alteração)

Antes de criar branch, editar arquivos ou abrir Pull Request, o agente **deve ler**:

1. Esta **POP 000**.
2. O **`AGENTS.md`** (resumo operacional).
3. A seção **"Publicação (GitHub Pages)"** do `README.md`.

## 3. Invariantes técnicas — NÃO violar sem autorização explícita

1. **Fonte do GitHub Pages = "GitHub Actions".** Não alterar em *Settings → Pages*. Trocar para "Deploy from a branch" **quebra a publicação automática**.
2. **O workflow `.github/workflows/deploy-pages.yml` não pode ser removido, renomeado ou desabilitado.** É ele que republica o site a cada push no `main`.
3. **Não remover o `.nojekyll`** (evita o processamento Jekyll no Pages).
4. **Não commitar diretamente no `main`.** Toda alteração passa por branch + Pull Request.
5. **Não mexer em configurações do repositório** (*Settings*: Pages, branches, secrets, colaboradores) **sem pedido explícito e por escrito do responsável.**

## 4. Fluxo de trabalho

1. Criar branch a partir do `main` atualizado.
2. Fazer as alterações e validar localmente quando aplicável.
3. Abrir **Pull Request** (preferencialmente como *draft*) contra o `main`.
4. Incluir no corpo do PR a **Declaração de Conformidade** (seção 5).
5. Aguardar revisão/merge do responsável. **Nunca fazer merge sem autorização.**

## 5. Declaração de conformidade (obrigatória em todo PR)

Todo Pull Request **deve** conter, por escrito, a seguinte declaração no corpo:

> ✅ **Declaro, por escrito, ter lido e seguido a POP 000 deste repositório.** Nenhuma invariante técnica da seção 3 foi violada. — _\<nome/identificação do agente\>_

Pull Requests sem essa declaração **não devem ser mergeados**.
