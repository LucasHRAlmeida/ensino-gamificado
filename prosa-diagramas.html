Framework Heurístico

Do significante (nome da via) ao significado biológico e clínico:

MUTAÇÃO / ALTERAÇÃO GENÔMICA ↓ Desregulação de via de sinalização ↓ Ganho ou perda de função em processo celular ↓ Aquisição de Hallmark(s) do câncer ↓ Consequência clínica (fenótipo, prognóstico, alvo terapêutico)

Os 14 Hallmarks (Hanahan 2022)

  1. Sustained proliferative signaling — Proliferação autônoma
  2. Evading growth suppressors — Evasão de supressores
  3. Resisting cell death — Resistência à apoptose
  4. Enabling replicative immortality — Imortalidade replicativa
  5. Inducing/accessing vasculature — Angiogênese
  6. Activating invasion & metastasis — Invasão e metástase
  7. Reprogramming cellular metabolism — Metabolismo reprogramado
  8. Avoiding immune destruction — Evasão imune
  9. Genome instability & mutation — Instabilidade genômica
  10. Tumor-promoting inflammation — Inflamação pró-tumoral
  11. Unlocking phenotypic plasticity — Plasticidade fenotípica
  12. Non-mutational epigenetic reprogramming — Reprogramação epigenética
  13. Polymorphic microbiomes — Microbioma polimórfico
  14. Senescent cells — Células senescentes pró-tumorais

Bloco I — Via RAS-MAPK

Fator de crescimento → RTK (EGFR/HER2/FGFR/MET) → GRB2-SOS → RAS (GDP→GTP) → RAF → MEK → ERK → FOS/JUN/MYC → proliferação

Genes-chave: KRAS NRAS BRAF V600E EGFR HER2

Hallmarks principais: 1, 3, 7

Fármacos: erlotinibe, osimertinibe, sotorasibe, adagrasibe, vemurafenibe + trametinibe.

Conceito central: RAS é o interruptor molecular. Mutações G12/G13/Q61 travam o estado GTP-ligado.

Bloco II — Via PI3K-AKT-mTOR

RTK/GPCR → PI3K → PIP2→PIP3 ← PTEN (freio) → AKT → mTORC1 → síntese proteica + inibição apoptose + Warburg

Genes-chave: PIK3CA PTEN AKT1 TSC1/2

Conceito: Haploinsuficiência de PTEN já confere suscetibilidade. Perda de uma cópia reduz a dose funcional o suficiente para desequilibrar o eixo.

Bloco III — Via p53-MDM2

Dano DNA → ATM/ATR → fosforila p53 → estabilização → p21 (parada), BAX/PUMA (apoptose), MDM2 (feedback)

Genes: TP53 MDM2 ATM CHEK2

Conceito avançado: Mutações missense de TP53 frequentemente exercem efeito dominante-negativo + ganho de função. A proteína mutante se incorpora ao tetrâmero e inibe a wild-type.

Caso brasileiro — TP53 p.R337H

Mutação fundadora comum no Sul/Sudeste do Brasil. Explica clusters de carcinoma adrenocortical pediátrico (CAP). Penetrância incompleta (~3,9–10% para CAP até 12 anos). Haploinsuficiência condicional por pH no córtex adrenal fetal + efeito DN. Triagem neonatal no Paraná identificou ~1:375 portadores. Vigilância com USG abdominal semestral detecta tumores precoces e melhora sobrevida.

Bloco IV — Via RB1-CDK4/6-CCND1

Mitógenos → Ciclina D → CDK4/6 → fosforilação de RB → libera E2F → entrada em S (ponto de restrição)

Freios: p16 (CDKN2A), p21, p27.

Genes: RB1 CDKN2A CCND1

Interseção Metabólica (Hallmark 7)

mTORC1 ativo reprograma o metabolismo para efeito Warburg (glicólise aeróbica): ativa HIF-1α, GLUT1, hexoquinase, LDHA. Nutre biossíntese necessária à proliferação rápida.

Como usar este mapa

Conecte mutação → via → hallmark → fenótipo → alvo. As vias conversam entre si (PI3K ativa mTOR; RAS ativa PI3K; p53 conversa com RB). A compreensão das intersecções separa memorização de raciocínio clínico-molecular.
